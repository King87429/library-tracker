# 📚 Library Tracker System

A simple and effective **Library Management System** built using Python.  
This project allows users to manage books, register members, borrow and return books, and automatically store all data in JSON files.

---

## 📌 Features

- Add new books to the library  
- Register library members  
- Borrow and return books  
- Validation for book availability  
- Automatic storage in `books.json` and `members.json`  
- Simple analytics report  
- Fully menu-driven console interface
